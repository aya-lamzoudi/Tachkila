Tachkila - Composition d'équipe
1. Travail réalisé
Création d'une application web interactive pour composer une équipe de football en formation 4-4-2.
Création d'un terrain de football avec CSS Grid contenant les 11 positions des joueurs.
Création d'une interface permettant d'ajouter, de modifier et de supprimer des joueurs.
Création d'une liste de joueurs affichant leur nom, leur numéro et leur poste.
Intégration d'un système de couleurs pour distinguer les gardiens, les défenseurs, les milieux et les attaquants.
Mise en place d'un système d'affectation des joueurs aux positions compatibles avec leur poste.
Gestion des positions libres et occupées.
Ajout d'une fenêtre modale pour gérer les informations des joueurs.
Mise en place de la validation des formulaires avec des expressions régulières.
Affichage de messages de succès et d'erreur.
Sauvegarde des données avec localStorage.
Adaptation de l'interface aux ordinateurs, tablettes et mobiles.
2. Technologies utilisées
HTML5 pour la structure de l'application.
CSS3 pour le design et la mise en forme.
Tailwind CSS pour créer une interface responsive.
CSS Grid pour construire le terrain et organiser les positions.
JavaScript pour gérer les joueurs, les événements et les interactions avec le DOM.
LocalStorage pour sauvegarder les données dans le navigateur.
Git et GitHub pour sauvegarder le code et suivre les modifications.
Vercel pour déployer l'application en ligne.
